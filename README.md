# 30秒時給診断

既存の `jikyu-shindan` Next.js App Router / TypeScript / Tailwind CSSプロジェクト。18歳以上の女性向けに、夜職の仮の参考時給・月収目安を6問で表示し、公式LINE無料相談へ誘導します。一般会社員向けの実質時給計算は削除済みです。

## ローカル起動

Node.js 20.9以上（推奨24 LTS）。

```bash
npm install
npm run dev
```

http://localhost:3000 を開きます。

```bash
npm run lint
npm test
npm run build
npm start
```

## 公式LINE設定

`.env.example` を `.env.local` にコピーし、`NEXT_PUBLIC_LINE_URL` に運営する公式LINEの友だち追加URLを設定します。`https://line.me/...` または `https://lin.ee/...` のみ対応。空欄・無効なURLでは、相談ボタンを無効にして準備中と表示します。仮URLや架空のアカウントへは誘導しません。

公開URLなので秘密の値ではありません。NEXT_PUBLIC環境変数はビルド時に埋め込まれるため、変更後は再ビルド・再デプロイが必要です。

## Vercelへの反映

既存のGitHubリポジトリとVercelプロジェクトをそのまま利用します。mainへのpushで、GitHub連携済みのVercelは自動デプロイします。

VercelのProject Settings → Environment Variablesで以下を本番用に設定し、再デプロイしてください。

- `NEXT_PUBLIC_SITE_URL`: `https://jikyu-shindan.vercel.app`（独自ドメイン使用時はその本番URL）
- `NEXT_PUBLIC_LINE_URL`: 実際の公式LINE友だち追加URL。未設定でも診断は利用可能。

Next.js・ルートディレクトリ `./`・標準のnpmビルド設定で動作します。DB・ログイン・管理画面はありません。公開URL未設定時はVercelの `VERCEL_PROJECT_PRODUCTION_URL` を使用し、ローカルではlocalhostへフォールバック。

## 診断と計算

質問順: 年齢（18歳以上）→希望エリア→業種→経験→週の出勤日数→1日の勤務時間。選択式の質問は選ぶと自動で次へ進みます。年齢・日数・時間は入力して次へ。戻るボタンで回答を変更可能。

`lib/calculation.ts` の金額・係数はすべて仮のシミュレーション設定です。求人データ・実際の査定・公的統計には基づかず、給与・採用を保証しません。画面にも明記しています。

- 仮の基礎時給: キャバクラ2500–4500円、ラウンジ2500–5000円、ガールズバー1500–2500円、セクキャバ2500–4500円、いちゃキャバ2000–4000円。
- 仮のエリア係数: 東京1.2、首都圏周辺1.1、関西1.1、愛知1.05、福岡・その他1。
- 仮の経験係数: 未経験・ブランクあり1、1年未満1.05、1年以上1.15。
- 参考時給: 基礎時給 × エリア係数 × 経験係数。100円単位で四捨五入。
- 月収目安: 参考時給 × 週の出勤日数 × 1日の勤務時間 × 4週。税金・店舗控除・休憩・欠勤・バック・賞与・交通費などを考慮しない控除前の概算。
- 年齢は対象者の確認のみ。時給計算に影響しません。18歳でも高校在学中などの場合は店舗への応募資格を確認するよう案内。
- 入力範囲: 年齢18–100歳の整数、週1–7日の整数、1日1–8時間（0.5時間刻み）。

## プライバシーと確認

回答はブラウザーのReact Contextでメモリ内のみに保持。サーバー送信・Cookie・ブラウザーストレージ・URL保存なし。再読み込みで消去。LINEへの回答自動送信もありません。結果のシェア機能は削除済み。詳細は `/privacy`。

確認例: 22歳・東京・キャバクラ・未経験・週3日・1日4時間 → 時給3000–5400円、月収144000–259200円（仮値）。

公開後はスマホ表示、18歳未満の入力エラー、6問の遷移、戻る・再診断、LINE未設定時の無効化、設定後の公式LINEへの遷移、robots/sitemap/OG画像を確認してください。診断・結果はnoindex。
